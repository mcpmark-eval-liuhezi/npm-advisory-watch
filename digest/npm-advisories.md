## Notable themes for the talk

- **Sandbox escapes are back**: `vm2` alone accounts for 5 advisories (2 critical, 3 high) — denylist gaps (`child_process` omission), CLI host-realm `require()`, `fs/promises` bypass, `node:test.run()` execArgv, and `https.globalAgent` exposure.
- **JWT libraries keep failing closed-open**: `fast-jwt` has 4 advisories in this window (1 critical, 3 high) — empty-key bypass, algorithm confusion via non-whitespace prefixes, raw JWK treated as HMAC secret, and array-payload validator bypass.
- **Batch disclosure days**: 2026-10-06/07 saw coordinated Ghost + Payload release waves (16 advisories in ~28 hours).
- **Dev-tooling as an attack surface**: Storybook (critical, code injection from malicious websites), Claude Code (hash-pin bypass), knowns (LSP binary config RCE), launch-editor/vite (Windows path bypass) — all high or critical.
- **MCP ecosystem**: 3 advisories across `@modelcontextprotocol/sdk` / `server` — cross-client message delivery, memory exhaustion, and cross-session task access.
